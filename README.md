# EmailBot

Bot RPA de **correo empresarial**: lee los buzones corporativos (IMAP, Gmail, Microsoft 365), clasifica cada correo con reglas e IA, lo enruta al bot o área que corresponde, convierte consultas en tickets con SLA y envía los correos transaccionales y de cobranza de los demás sistemas.

Stack: **Python 3.13 + uv · FastAPI · SQL Server / Azure SQL · Redis · colas (Dramatiq) · Docker**, desplegable en un VPS (Docker Compose) o en Azure Container Apps.

> **Estado**: en desarrollo. El plan por fases está en [ROADMAP.md](ROADMAP.md).
